## Daftar Periksa Dokumen

| Status | No. | Jenis Dokumen | Keterangan & Rincian Kelengkapan | Lokasi File / Catatan |
| :---: | :---: | :--- | :--- | :--- |
| [ ] | 1 | **Pedoman Pengawasan** | Meliputi siklus lengkap: perencanaan s.d. komunikasi hasil pengawasan | |
| [ ] | 2 | **Kertas Kerja Audit (KKA)** | Memuat komponen wajib:<br>- Daftar referensi<br>- Kriteria uji petik & ruang lingkup<br>- Langkah kerja & ROWD<br>- Sasaran, tujuan, kriteria<br>- Simpulan & temuan | |
| [ ] | 3 | **Surat Tugas (ST)** | Surat tugas resmi penugasan pengawasan | |
| [ ] | 4 | **Bukti / Dokumentasi Entry Meeting** | Notula, daftar hadir, foto/tangkapan layar, atau materi pemaparan | |
| [ ] | 5 | **Laporan Hasil Survei Pendahuluan** | Dokumen hasil identifikasi awal proses bisnis / risiko | |
| [ ] | 6 | **Risk and Control Matrix (RCM)** | Matriks risiko dan pengendalian terkait objek pengawasan | |
| [ ] | 7 | **Program Kerja Audit (PKA)** | Format file Excel (`.xlsx` / `.xls`) | |
| [ ] | 8 | **Bukti Supervisi / Reviu Berjenjang** | Riwayat/tangkapan layar reviu berjenjang pada aplikasi **TeamMate** | |
| [ ] | 9 | **BAPHP** | Berita Acara Pembahasan Hasil Pengawasan | |
| [ ] | 10 | **Berita Acara Temuan Sementara** | Berita Acara Hasil Temuan Sementara yang telah dikomunikasikan | |
| [ ] | 11 | **Bukti / Dokumentasi Exit Meeting** | Notula, daftar hadir, foto/tangkapan layar penutupan | |
| [ ] | 12 | **Laporan Hasil Pengawasan (LHP)** | Laporan final yang telah ditandatangani pejabat berwenang | |
| [ ] | 13 | **Hasil Pemantauan Tindak Lanjut** | Tangkapan layar (*Screenshot*) status tindak lanjut pada aplikasi **TeamMate** | |
| [ ] | 14 | **Bukti Pelaksanaan Tindak Lanjut** | Bukti dukung fisik/digital dari klien pengawasan atas rekomendasi | |
